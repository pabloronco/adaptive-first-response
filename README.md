# Adaptive First-Response Mission Engine

HackMIT 2026 — Sustainability.

A newly detected marine invasive species has an unknown true extent. The system maintains an explicit probabilistic belief under imperfect detection, allocates limited field effort, ingests new field evidence, updates belief, and replans the next mission.

Core loop:

`OBSERVE → INFER → DECIDE → SURVEY → LEARN → REPLAN`

Central demo thesis:

`FIELD EVIDENCE → BELIEF CHANGED → MISSION CHANGED`

This repository is the rehearsal implementation for the HackMIT project. Project-specific design decisions must remain consistent with the Project Freeze 3.0 documentation and subsequent Decision Log entries.
